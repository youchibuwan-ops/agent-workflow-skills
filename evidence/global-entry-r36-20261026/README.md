## 修复与安全边界

正常前端控制与模型工具分开：只允许精确初始化与项目信任配置，完整配置由宿主认证；实际异步完成后重启原生后端并重查状态。项目与文件路径继续核当前身份、私有边界、链接与字节一致性。

正常空闲退出保留签名待办，冷恢复重新核事实；真实故障、用户暂停及执行中退出仍保持失败保护。不会批量清除已签名失败。只读 queue/list 修复当前自有会话的队列初始化，queue/add、start、delete 等写入/执行接口仍拒绝。这里更新了较早宿主 README 的只读白名单范围，不代表全面启用队列功能。

独立只读审查分别复跑生命周期 3 项及队列边界 1 项；它们不是独立 GUI 或 OS 复现。完整全量、真实原生、界面与模型检查分别报告。
