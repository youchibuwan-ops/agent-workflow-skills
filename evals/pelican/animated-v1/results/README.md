# Actual animation A/B outputs

[Bilingual combined case and demo](../../README.md) now includes the actual GIF/MP4
comparison, contact montages, capture timing reports, public trace indexes and costs.

Open `A.html` and `B.html` in a browser to play the original editable animations offline. These files are exact actor outputs, not coordinator repairs. Both used gpt-6-astra/xhigh, the same task and tools, and caps of 900 seconds/80 registered primitive tool starts. A had no target Skill; B installed the frozen released SVG Skill. Static-round results remain separate and unchanged.

A completed in 519.18s with 22 registered starts. B saved this playable file but exhausted its 900s cap (900.09s recorded including stopping/draining; 55 starts), so primary completion was not observed. This is a time-budget outcome, not a false child-completion stop. No retry was made. Both files passed offline Chromium recording and self-contained SVG checks, which do not establish complete motion correctness or general Skill effectiveness.

Each was captured for two cycles, with 13 phase samples and enlarged contact review. `summary.json` includes exact hashes and the unblinded coordinator observations. No new independent blind scores were obtained and no winner is declared. The comparison recording is public; original raw browser recordings, process logs, source notes and drafts are retained privately. Raw RPC is not published because it can contain private/account content, hidden reasoning and copyrighted fetched material. No source photographs are included here.
