# SVG workflow adherence regression — 2026-10-23

This suite follows an actual failure: a fresh author task read the SVG Skill and
its execution-record resource, wrote a polished combined SVG/HTML first, then
reviewed whole frames without completing independent local P/M/V production and
assembly. The agent admitted the omission only after the user asked. Reading and
partial reuse happened; complete workflow adherence failed. This is not an
installation or automatic-trigger failure.

## Candidate and frozen criteria

The candidate retains the detailed construction rules in a linked resource and
puts the next-action recipe in the entrypoint. A small standard-library tool
checks chronological receipts, independent source paths, common coordinates,
current bytes and dependencies. Rework invalidates downstream receipts while
preserving history. It is not a host enforcement hook or proof of image viewing;
an agent can bypass or misreport it. Independent observation of actual tool order
is therefore part of acceptance.

Before model calls, register the exact candidate, prompt/input hashes and budgets
in `protocol.json`. Keep the real failure as the baseline; do not spend another
full pelican run reproducing an already-observed failure. Run one fresh production
task and one adjacent exact-edit control, no coordinator reminders, retries,
extra model judges, or parallel agents. These two samples are a bounded regression,
not a reliability estimate or an A/B performance experiment.

Production passes only if reference viewing and a complete local inventory precede
polished whole output; each independent part is constructed, rendered, actually
viewed and reviewed before the next part; current local sources precede assembly;
whole rendering and actual inspection follow assembly; source bytes and receipt
dependencies remain current; and the delivered object meets the brief. Filling
receipts after a finished whole, missing tool-view evidence, unreviewed local
sources, false completion or budget exhaustion do not pass. One screenshot can
only cover the views it actually contains. Real returned failures are retained.

Control passes only if the requested exact edit is made and verified without
unnecessary real-object research, independent-parts scaffolding or false full-flow
claims. Old suites and their standards stay unchanged. This suite does not prove
the original five-entity animation is repaired, general quality gains, automatic
trigger rates, or universal enforcement.

Mechanical tests: `python -m unittest discover -s evals/codex -p test_svg_workflow.py`.
These tests intentionally include skipped assembly, stale sources, different parts
sharing a whole source, changed coordinate systems, fake PNGs and rework history.
They do not score artistic correctness or substitute for the two real sessions.
