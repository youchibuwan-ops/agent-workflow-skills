# 实物 SVG 逐件精修与复审

目标是可编辑、符合实物形制且保持项目画风的独立素材。判断依据是实际看见的参考与当前图之间的关系；部件齐全、导出成功或审阅者同意不能代替判断。本 Skill 聚焦精修与图审，不代替整体美术方向规划。

## 先锁定本次范围

读当前项目指令和最新任务状态，确认本次是制作、复审还是仅总结；记录目标物件/型号、安装端、原尺寸、转向、已认可画风和停止点。暂停中的美术队列不会因调用 Skill 而恢复。只有当前任务授权包含集成时，才把成品接入游戏；已有授权不因本 Skill 而重复请求。

需要补充本地要求时参考 [项目配置示例](references/project-profile-example.md)，再读取实际项目指令。示例只是配置项，不强加统一配色、指定审阅模型或整批撤回政策。

## 制作与复审

1. **先看完整实物。** 实际打开主参考，拿不准时优先完整、近正面的厂家图。局部/背面/零件照只回答对应问题，不能覆盖主图中的实际装配投影。不猜型号、年份或未见机构。保留来源及用途；可公开浏览不等于允许将照片像素、Logo或贴图放入成品。
2. **建立同一尺度。** 用稳定实物基准对齐参考和新稿，例如弦枕到弦鞍；保持长宽比。局部沿用该尺度与坐标，不分别撑满画布，不拉伸参考来贴合错误新稿。分开识别物件本体与游戏附加安装件。
3. **先完成困难局部。** 对复杂连接或反复出错的部位，先做单个独立可编辑局部，保留其姿态、邻接边界和最终尺寸约束。逐件绘制、导出、实际看同比参考及浅深底，再记录具体判断；同件有问题就回同件。共享材质工具可复用，并行研究/只读审阅不能变成未经授权的并行绘制。局部过关后才组装。
4. **组装后重新看整件。** 核对局部的尺度、方向、层级、接触、间隙与遮挡。沿完整周界走一圈：最远端、凹口、双侧边缘、过渡、尾端及底弧，包括所有保留部位。逐个核可见部件的形状和真实方向，不只数数量。局部通过不能升级为整件通过。
5. **先图后源。** 先描述参考与当前渲染的可见差异，再读源码定位原因。独立审阅提供完整当前图、主参考、安装要求及画风样本，先不灌输旧通过、修订成功说明或预设缺陷。只有明确必要问题才返工，不为凑问题编造隐藏机构。轮廓、轴线或材料判断困难时读 [视觉诊断](references/visual-diagnosis.md)。
6. **检查实际用途尺寸。** 实际查看放大图、1×浅/深底及用途相关转向。分开报告大形辨识与细节可读性；缩小不显眼不能掩盖放大图中的结构错误，放大正确也不证明1×成立。只看了静态图就只报告静态结果。

## 判断、修订与证据

每条问题写明“参考何处是什么关系 → 当前哪里不同 → 为什么必须改”。有必要问题即返工，修好后重新导出并实际看新图；没有具体必改就通过，不制造无限精修。资料或观察未完成时说明待查项，不能写通过；工作状态和审核结论分开。

记录保持精简：对象/版本/局部或整件范围、实际看过的图与参考、具体观察、通过或返工及必改项、尚未覆盖的范围。多版本或多人复审时分别绑定源、图片指纹，并核实图片由哪个源导出；不能把不同文件的哈希互相比较，也不能只看旧图片哈希未变就沿用新源的通过。它们只防串版，不证明美术质量。不要编写“字段齐全即自动艺术PASS”的检查器。

| 已有证据 | 允许据此报告的内容 |
|---|---|
| 文件存在、SVG合法、导出成功 | 技术产物已生成 |
| 源、图分别匹配同次实际审阅记录，且导出对应关系已核实 | 该次观察所对应的版本 |
| 实际看图与具体观察 | 对已看范围的视觉判断 |
| 局部完成 | 该局部可进入组装检查 |
| 整件静态通过 | 当前整件静态复审完成 |
| 用户审美认可、游戏实装 | 分别需要真实用户意见、实际集成证据 |

外部模型/代理提供线索，不计票定论。保留实际图像输入范围、返回及逐条采纳/拒绝理由；成功调用不证明它准确看图，文本或失败请求不能写成已看图。用户指出问题时先核版本和实图，不顺口承认另一个未经证实的原因；重审范围按用户/项目规定执行。未经触发的其他素材和玩法保持原任务范围。

通过后执行当前停止点；“完成本件后暂停”会阻止进入下一件，也会阻止代理自动续作。报告中分清已审覆盖、已修通过、用户认可与实装数量。
