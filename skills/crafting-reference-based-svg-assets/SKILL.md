# 实物 SVG：按证据逐局部制作与复审

产物是符合实物形制、保持项目画风的可编辑素材。用当前实图与参考判断；文件齐全、导出成功、填写记录或审阅者同意均不能证明画对。

## 执行入口与顺序

先读项目指令和最新用户要求，确定制作、修订、只读复审或仅总结，以及对象/型号、目标视角、安装端、用途尺寸、转向、已认可画风与停止点。需要配置项时看[项目配置示例](references/project-profile-example.md)。不因调用 Skill 恢复暂停任务，也不扩大集成、发布或外部调用权限。

执行顺序固定为 **范围 → 参考与结构判读 → 局部清单 → 逐局部制作/对照 → 回装 → 整件复审 → 交付**。每步先完成下表的实质动作，再进入下一步。缺证据就处理缺口，不以工期、缩小后看不出、旧通过或“稍后补审”跳过。

| 阶段 | 实际动作 | 进入下一阶段的条件 |
| --- | --- | --- |
| R 参考与结构 | 打开候选图；核角度、尺度、可见结构及相互矛盾 | 主要轮廓、材料、局部轴线与连接关系有可见依据；剩余未知明确且不影响将要画的范围 |
| L 局部清单 | 沿整件周界和内部装配列全可见局部，含保留部分、重复实例和接点 | 每个局部有身份、参考、邻接关系、最终坐标/尺寸约束和本次动作 |
| P 单个局部 | 只处理当前局部；独立源 → 导出 → 实际打开同比图与浅深底 → 具体判断 | 当前局部无必改项；有问题就在本局部修后重看，再处理下一项 |
| A 回装 | 将全部已核局部按已定尺度/姿态回装，核层级与邻接 | 清单每项有当前实图依据；组装无未解释的位移、缩放或几何变化 |
| W 整件复审 | 重新看完整参考、当前整件、接点放大、1×浅深底及相关转向 | 完整周界、所有局部和局部间关系均已实际检查，无必改项 |

多局部或跨版本任务使用[执行记录模板](references/execution-record.md)，保存于项目指定位置；简单单局部可在现有记录中简记同样的事实。记录用于暴露漏项，不是自动放行条件。

只读复审不擅自绘制：先核现有源/图与清单，再审当前证据；缺失的局部或过程如实列出，不能代补想象。任务要求停在研究、局部或总结时，在该阶段停止，不强行做完整制作。

## R：先判读参考，再动源

1. **多个候选必须实际打开。** 对同一关键部位主动比较多个候选的角度与可见范围，不在第一张貌似合适的图停止。正面目标先找真正近正视图；文件名 Front 不证明正视。斜视目标按其目标投影核查。
2. **互补视角解决具体盲区。** 每张图明确用于轮廓比例、厚度、材料还是连接；用侧/背/局部/不同光照区分阴影、反射、断口、孔隙和实体。几张相似斜照不互相证明共同看不见的部分。辅助图与主图冲突时回查判读，不因主图选得早就忽略其他视角。
3. **先把关系说清。** 对将要制作的每个接点指出：哪些部件连续，哪里断开，哪条腿进入哪个口，哪个面遮住哪个面。分别核轴向、端面投影、厚度和前后位置。两腿/两入口逐一追踪，不能以“藏进板后”代替连接依据；零件看起来像圆筒也不证明它和相邻面处于正确空间关系。先写参考与当前图的可见差异，再读源定位。
4. **统一尺度，不拼凑型号。** 主参考用稳定实物基准对齐，保持长宽比；局部沿用共同坐标，不各自撑满画布。近照没有共同量尺就只作定性依据。核同款、同状态、手性及相机偏角；不同尺寸/型号图只能解释已核实的共通构造，不能移植比例或未知机构。本体与游戏安装件分开。
5. **推断有前提。** 实际搜索仍找不到适用视图时，记录检索词、来源、已打开候选、逐项排除理由和推断范围。影响主轮廓、轴线、厚度或连接的未知，先查清而不放行。不可见内部不强行重建；不得借“不可见”回避图中已有的错误。

保留来源与用途；公开可读不等于允许分发像素、Logo或贴图。诊断困难时读[视觉诊断](references/visual-diagnosis.md)，不把诊断提示当预设缺陷。

## L/P：清单落到每一局部

- 清单覆盖整件。可将一个复杂接点连同邻接面作为独立局部；连接检查不能把邻接面都裁掉。同类构件按各自实例检查姿态、轴线和接触，不用一个通用符号旋转几次替代。
- **局部特征不等于独立零件。** 清单先标所属实体：同一根线的弯头、同一张钢片的板面/折边/卷口可以分局部检查，画面仍须连成一体。沿实体跨过局部分界，核轮廓切线、粗细/片厚、材料明暗和遮挡是否连续；真实折痕可以保留，连续连接处不能误画成封口、接缝或悬空管件。接点消失先查原构件及层级，不另补一小截冒充连接。
- 按清单逐项推进。每项留下：参考具体位置 → 当前可见关系/差异 → 必改理由或保留依据 → 本次源与实际渲染 → 复看结果。保留原有正确部分，不为完成清单无差别重画。把旧整图拆成文件、列出部件或检查 XML 不算完成这些动作。
- 关键局部把辅助视角落实为判断：指出另一张图的具体位置、它能确认/排除的解释，以及因此修改或保留的当前几何；不能只列图名或“已参考”。改实体轮廓前，先在照片指出实体边界与投影的分界；若只有一片暗块或别人的“缺件”意见，回 R 查证，不先补板、凸缘或孔。辅助图不能解决的关系仍是未知，不硬套异款尺寸。
- 局部先核大形/材料/方向，再核断口、入口、间隙、接触及遮挡；用同尺度并排图检查，不通过拉伸参考来贴合新稿。看放大图和用途尺寸的浅深底，区分结构错误与可读性问题。
- 确有必改就返工到当前局部；修后重新导出并打开新图。一个局部完成后才做下一项，全部清单完成后才回装。并行只按项目许可做研究/只读审查，不变成未经授权的并行绘制。

## A/W：局部通过不能替代整件

回装保留已核局部的坐标、姿态及几何。若必须改动，重新审受影响局部与邻接关系；“原样回装”也仍需新整件复审。

已确认同一杆线穿过卷筒/孔隙再露出时，先看去掉遮挡的完整构件检查图：入口、被遮段与出口的路径、轴向及粗细须相容；再恢复遮挡，沿整条构件复看。出口不能另画一个亮点冒充同一杆。此检查只核已确认的关系，不凭空重建未知内部，也不能用“内部未知”跳过可见两端的矛盾。

实际沿完整周界走一圈：最远端、顶尖/凹口、两侧、过渡、尾端和底弧。再逐项核全部保留/新增局部及接点：前后轴向、端面投影、相互间距、片材连续/断口、腿与入口对应、接触、遮挡。孤立正确的部件可能回装后穿错面或盖住入口。

打开整件放大图、1×浅深底及用途相关转向。旋转同一张图只验证屏幕辨识，不等于获得新相机视角；细节缩小后不显眼不能掩盖放大结构错误，放大正确也不证明1×可读。

独立复审提供当前完整图、参考、安装约束和画风样本，不提供旧通过或预设答案。逐条核返回与实图，分别采纳/拒绝并写依据；审阅人数、调用成功、文本摘要或失败请求都不算真实图审。用户指出问题时先定位版本和关系，不能顺口承认另一个未经核实的原因。

## 版本、结论与停止点

- 源、渲染与审阅对应同一版本；修改源后重导，核实导出对应关系。哈希用于防串版，不证明质量。修改局部会使其旧结论及相关装配/整件结论失效；批量失效范围服从项目规则，不强加给其他项目。
- 资料/观察未完是工作未完成，不是审核通过。审核只对已实际检查范围给**通过/返工**；有明确必改则返工，没有必改不无限精修。不能为了凑结论发明隐藏机构或问题。
- 交付写清当前版本、实际看过的范围、具体观察、限制和证据位置。静态审查、用户审美认可、动态表现和游戏实装分别需要各自证据；不能相互升级。
- 按当前任务停止点结束；“完成本件后暂停”阻止进入下一件。未授权不集成，不以技能维护恢复暂停队列。

## 修改本 Skill 的验收

规则改动后进行实际执行测试，不以检查字段、标题或复述规则验收：

1. 保留修改前版本与实际漏步/误判证据；已有基线正确时如实记录。
2. 用未参与规则编写的新物件/关键部位，让独立 agent 只拿 Skill、真实任务和最少原始材料执行；不预告应查出的答案。观察实际搜索/打开图/逐局部处理/停止与回装行为，保留原始产物及失败。
3. 新参考研究只能验证研究阶段，不能冒称验证制作与回装；这些阶段还需真实局部与整件任务证据。另测相邻反例，如已有精确自有源的平面图标改色，应直接编辑而非启动实物研究。
4. 查漏步、旧图沿用、只填表、无证据放行与越过停止点。未做到则修订再测；单次成功不宣称普遍提升或保证不会再错。
