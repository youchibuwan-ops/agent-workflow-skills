# 实物 SVG：证据、制作、审核闭环

目标是按参考与项目画风完成可编辑素材。必须实际检查几何和实图；文件齐全、步骤复述、渲染成功或审阅者同意都不是质量证明。当前任务有未解决必改项时继续返工，不以一次修改或提交结束。

## 先确定范围与执行顺序

读最新用户指令和项目约束：对象/状态、制作或只读范围、目标视角、用途尺寸/转向、认可画风、安装端、保留项和停止点。抽象图标或精确自有 SVG 的简单改色直接编辑，不启动实物研究。项目特有约束参考[配置项](references/project-profile-example.md)。

**先匹配能力，再补实现。** 定位时核已安装 Skill；出现新专业缺口、陌生工具或反复同类失败时，在继续写脚本前重新匹配并搜索相关 Skill。有 `proactive-skill-discovery` 就用其发现、源码/许可核查、适配和验证流程；未安装时也先查现成方案的实际能力、依赖和适用边界，再决定薄适配或补实现。常规修改复用已核流程，不为每个坐标重搜；搜索/安装本身不放行当前关卡。复用工具还须核其几何假设、实际绘制形状和审核覆盖：凸包、封闭体或包围盒检查不能证明非凸片材的开口、连续管路或面/线遮挡。

执行链固定为 **对象与纠正定位 → 参考判读 → 整件基准/局部清单 → 单局部几何 → 单局部材质 → 单局部审核 → 回装 → 整件审核**。缺少适用步骤、缺关键证据或有未解决必改项，禁止下一步，也禁止报完成或结束当前任务；必须执行补证据/修正/复看闭环。后一步不能补签前一步。记录使用[执行记录](references/execution-record.md)，简单任务可简记同样的事实，不制造空表。

**开画前先过结构门槛。** 必须能对当前范围逐实体说明：有几个实例、各属哪一物体；从哪里连续到哪里；根部/折卷/自由边的有向路径；相邻面、轴向及谁遮谁，并对应实际参考位置。只数对零件、看着像、套用熟悉原型或模型内部自洽，都不足以放行。影响可见轮廓/连接/遮挡的关系未查清，留在 R/B 实际补证据；可用粗构造检验解释，但不先精绘、配色再补结构理由。

重复构件、孔和接点先按**所属面与空间位置逐个编号**，对每个实例指出在哪个视图的哪处可见、在哪处被遮挡/投影重合；先分别清点各面，再核整件总数。不能从一张投影看少了就删除实例，也不能只写总数或“多视角已看”。图太小就放大该处，清单与实图有冲突先重看并修清单。只读 R/B 研究也须完成这个核对，不能留到绘制时才查。

| 阶段 | 必须实际完成 | 不满足时的动作 |
| --- | --- | --- |
| 定位 | 在参考与当前图中指出同一实体、同一段边/面/接点；确认本次要求与原有约束 | 先定位，不能直接选一个看似有关的局部开画 |
| R 参考 | 核当前来源；有不确定关系时打开多候选及互补视图，查清形制、空间关系和证据边界 | 继续查具体缺口，不以图数或检索耗时放行 |
| B 基准 | 用主图统一尺度/姿态、关键端点与整体结构；列全可见局部及邻接 | 补基准和漏项，不能独立局部各自撑满画布 |
| P 几何 | 当前单局部的轮廓、尺寸、截面、透视、连接一起成立 | 修几何并重新看图，不先用材质遮掩 |
| M 材质 | 在已核几何上表达厚度、材料与项目光源，细节不改变结构 | 回 P 或修材质，不靠亮线假装改了实体 |
| V 局部审 | 同尺度参考/当前局部、邻接、放大与用途尺寸实际对照；无未解决必改 | 留在当前局部返工，不能切下一件或报完成 |
| A 回装 | 全部局部完成后，按同一基准原样组装；复查接点与层级 | 有变化退回受影响局部，不能拿局部旧通过代替 |
| W 整件审 | 当前整件完整周界、全部保留/新增部分、跨局部连续性及用途视图重新审核 | 退回具体缺陷；修后重审受影响关系和当前整件 |

任务只授权研究/只读/单局部时，在该范围执行，不为凑齐链条越权绘制或集成。整体基准可用粗略构造草图锁姿态与尺度，不能用精修整图替代要求独立完成的局部。

**关卡凭实际证据放行。** 每次转阶段先核当前源和由它生成、实际打开的图，在同一记录中留下：当前阶段/局部与版本 → 已执行动作及可打开的产物 → 参考位置与具体观察 → 必改是否清零 → 下一动作。没有发生的操作、缺失/过期产物、只有“符合/通过”的判断都不能放行。可自动核的版本、资源、覆盖和连接用现成工具实际核；这些结果不代替实物与图审。

参考的使用也须闭环：**待判问题 → 图中可见依据及排除的解释 → 当前几何/保留决定 → 修改后同位置的实际复看**。只下载、列链接、写摘要，或资料能回答却仍标“不确定”，该项未完成。一个解释若与其他适用视角冲突，回 R/B 修解释，再重查其尺寸/遮挡后果；不能只挑支持当前稿的图片。

## 代理自行推进，不等用户逐项提醒

开始及恢复工作时，实际核当前源/图与记录，确定**最早未满足的阶段、当前局部、具体缺口、下一动作**。据此选择行动；“已看过”“已通过”的旧文字与当前图冲突时，以当前实图为准，撤回受影响结论。不能从上次总结中的最后一步直接往下接。

每次修正后主动检查本项全部约束及受影响邻接，再执行下一动作：缺参考就查并用，几何不成立就构造/修改，图过期就重导并打开，有必改就返工；当前局部无必改才取清单下一项。全部局部完成才回装，当前整件完成复审才进入交付。禁止用“还可以继续”“等用户指出下一处”把这些必要动作交回给用户。

用户发现漏项说明当前检查失效：先处理具体缺陷，同时回查同类实例、相邻连接及它影响的整件关系，更新检查依据；不能只修被点名的坐标。发现与处理应来自代理自己的实图对照，不能把用户反馈次数当流程驱动力。每轮更新当前项与下一动作即可，不为记录制造文件。

## 定位：不能把反馈变成自定任务

用户说“上缘、下缘、这里、长短”时，先在参考和当前图定位所指边界及两端，区分屏幕方位与实体方向。只有一个合理对象时直接推进；仍有多个解释且会改变几何时，先准备带标记的具体对照，再问一个明确问题。等待时可做无关此歧义的已授权核查，不能先按猜测修改。

把约束一起保留：修起翘不能丢尺寸，修局部不能丢整件连续性。先看图写出可见差异及参考位置，再读源找原因。不能先改坐标，再把坐标比值当作参考依据；不能顺口承认用户没有指出、实图也未核实的缺陷。

## R：先解决判读，后决定几何

精确自有工程源已明确同一目标视角的几何，或已有参考完整覆盖本次范围时，实际核该来源即可完成本项；不为凑步骤重搜异款。存在关键判读缺口时执行以下检索，不以已提供图片为由跳过。

1. **找多个实际候选。** 同一关键部位主动比较多个候选并打开图像，不能第一张貌似合适就停。正视目标先找真正近正视图；文件名 Front 不证明角度。斜视目标按目标投影核查。
2. **每张图解决具体问题。** 写出图中具体位置、角度/型号/状态、能核的轮廓/厚度/连接，以及不能核的部分。参考角色按部件和待判量指定：用户选某图核主体尺寸，不等于该图也能核手柄形状或深度。侧、背、端面、不同光照互相核实；数张同类斜照不能证明共同盲区。辅助图必须落实为修改/保留/排除哪一种解释。
3. **先分清实体。** 哪些是同一根杆/同一张片，哪里连续折弯、哪里真实断开、哪条腿进入哪个口、哪面遮哪面？区分阴影、反射、孔隙与材料边界。片材的根部、凸起、回转与自由边分别核，不能把卷曲画成平倒角或闭筒。
   相对两侧或重复的卷/折构件，要分别沿所属片面追到附着根，再绕曲壁追到自由端，核截面旋向与开缝方向；不能只平移一个看似合适的筒壳。内侧根与回返自由端是不同约束。发现一侧形成方式错时，自行重查整个对应组，不等用户指出另一侧；未经同一结构依据复核的旧“看着还行”结论撤回。
4. **证据有用途边界。** 主图约束目标投影、位置与可见比例；异款辅助图可说明共通结构，不能直接移植精确尺寸、手性或隐藏机构。辅助图同一排/面上的同身份边界仍可提供带误差的相对跨度，用来排除主图误读；不能笼统标作“只看结构”而丢掉可用比例。先核真实宽度方向，分别量根部、自由边、端段和缺口，再回主图对应边界，不能用口中心冒充段端点或预设等分。照片测量只用清楚边界与共同基准，标明遮挡和误差；精确自有工程源按其明确尺寸。
5. **推断必须经过检索排除。** 实际搜索仍找不到适用视图时，记录词、来源、已打开候选和逐项排除理由，再限定推断范围。影响当前主要形状/尺寸/连接的未知继续查；需要用户明确选择时提出具体缺口。不得自选比例“凑对关系”，也不凭空重建无关内部。

宣布“不确定”前，先区分**代理尚未查清**与**证据确实不能回答**。把具体待判关系逐一对回所有已打开的互补图：哪处可见边/端面/缺口已能排除哪些解释？已有照片足以回答时就完成判读并落实几何，不能因主图暗、不是同一拍摄角度或尚未使用那些照片而继续留疑。必要时继续找更适用角度并实际比较。只有这些动作后仍无依据的特定隐藏量才保留未知，列明哪些可见关系已确定；不能用“内部尺寸不明”笼统搁置整个接点或逃避制作/审核。

**先判断视图能否区分结构解释。** 屏幕上的曲线不证明构件沿深度弯曲；倾斜投影也不能证明它共面。对共面/出平面弯折等会改变结构的分歧，分别说明候选解释及哪种证据能排除其中一种，优先查适用的完整正面与侧面/端视并核构件身份、状态和接口。未排除投影歧义前，不能据此精绘空间弯曲或反推长宽；沿猜定平面反投影、调相机、转同一模型和单角度叠合都不能补出缺失的深度证据。先用可见连接与连续路径约束整件，再细化局部。

**资料少时，改用约束驱动的有限推断，不以图量或三视图齐全作为门槛。** 先提取已有图能确定的轮廓、接口、连续、遮挡和已知尺寸；对称、标准件与制造方式仅作待核先验，不能冒充实测。只为会改变当前交付的具体歧义查新增证据，优先信息互补的实拍、尺寸图、拆解或可靠规格，不重复收集同类斜照。仍有分歧时列少量候选，用粗线框/截面检验全部已知约束、安装/运动和穿插；记录排除了什么、仍不能区分什么。一个方案能解释所有现有图，不代表它是唯一真实结构。证据足以满足当前可见交付即可推进；非关键隐藏量可限定假设及适用范围，不编精确尺寸。影响主要轮廓、连接、运动或所要求多视图的歧义未解决，不能放行相关 P；说明已查证据与最小缺口，再请求必要的补拍/测量或假设选择。外部证据确实不可得时如实保留阻塞及可独立完成部分，不无限搜索，也不假装完成。

保留来源与许可；可访问不等于可分发像素。疑难时读[视觉诊断](references/visual-diagnosis.md)，其中提示不是预设缺陷。

## B：整件基准与完整局部清单

用同一实物尺度锁整体长宽、主轴/面方向、主要端点、部件相对位置及安装端；不拉伸照片、不把不同近照拼成量尺。看完整物件，包含最远端、尾部和保留部分。

同时锁定项目认可的材质色/明度角色、描边和光源，并记录最终画布及物件实际占用尺寸。同类材料与重复件共用这些基准；不同材料保留应有区别。局部检查图可以同比放大，回装不得各自归一化尺寸、任意换色或改粗细。尺寸与颜色一致性从 B 贯穿每次局部审核及 W，不能最后才统一染色。

**严重失误警戒：沿用旧色值不等于颜色正确，内部一致也不等于材质正确。** 先从实际参考区分涂层本色、裸材、反射与光照，再明确它们如何转换到项目画风；保留部件之间的真实明度/色相关系。黑色涂层钢片不能因旧稿或统一蓝灰色板而画成浅色裸金属，同一片上的卷边也不能另换材质。不同光照/曝光的照片只能互核角色，不能盲吸一个像素作本色。实际打开主参考、认可画风和当前局部/整件，比较主体色块、材质间区分与明暗面积后才可通过 M/V；未经此项核查不得说“颜色已正确/一致”。发现旧基准错误时撤回受影响局部与整件的颜色结论，重定基准并逐项复查，不能把错色延续叫作保留画风。

先检查对齐问题再改形：若多个分散端点同向偏移，先核裁切、整体姿态、尺度及投影；只有某个局部不符时再改局部几何。比较一次几何修订时固定参考、裁切、姿态和尺度，不能通过换视角或拉平厚度制造吻合。外轮廓之外还核开口、间隙等负空间；单视图叠合不证明厚度与连接。

**透视必须共享整件约束，不能逐局部自定相机。** 将参考中可核的轴族、相邻面、端面形状及遮挡顺序一起定位，再在当前图逐项对应。圆口的椭圆朝向/压缩、筒身轴向、同轴/平行关系和所在板面必须能由同一投影解释；不能只把椭圆转得像。使用构造模型时，近似相机也须与这些整件关系相容；同一局部的多视图自洽、两个根点对齐或一条边的角度接近，都不能核定整件透视。发现不相容立即回 B/P，撤回受影响结论，先解决共同投影再细化局部；不可用画风、配色或任意局部拉伸掩盖。

**长、宽两向分别核，实际参考视角分别对。** 每个关键局部既量轴向起止/分段，也核横向展开、截面及负空间，不能对齐一条轴就签尺寸通过。把同一结构转到能够回答该问题的实际参考视角，在共同尺度下并排比较，再回目标视角复查；几个方便的模型角度不能代替。记录几何差异、相机拟合残差及异款差异各自依据，不能把它们混为一项，也不能为了匹配某一图而单独变形局部。

逐项列：**局部身份/所属实体 → 参考位置 → 邻接 → 共用尺度与端点 → 已知/待查 → 本次动作**。重复件按实例列明；两腿/两入口分别追踪。局部切分只方便制作，不把一根杆、一张片拆成互不连续的零件。

用互补视角核清同类结构的**完整实例数及左右/前后对应**，逐个映射到当前源和可见/被遮范围；不能从主图最显眼的一侧生成清单。已证实存在但被遮住的构件也要说明谁遮它、露出哪里，不能直接漏列；也不能为了显示齐全把本应遮住的部分透画。先核实例覆盖，再审每个实例的局部细节。用户指出漏件时回查整个对应组并重开受影响邻接，不能只补一个符号便结束。

## P/M/V：每一个局部都走完整循环

按清单逐个完成，不能只精修用户点出的一个角落：

1. **回读本项全部约束。** 指出主图和辅助图的具体位置；当前差异是什么，证据支持改哪里、保留哪里？关键关系未清先回 R。正确部分有依据地保留，不无差别重画。
2. **先构造独立局部几何。** 沿用已有独立源或按已核基准建立本项可编辑源，保留整件坐标；之后只修改当前局部。在共用坐标中核大形/长宽、各边起止点与收缩、厚度/截面、面和轴的投影、前后关系、断口/入口及接触。它们相互约束，不能逐项打勾后互相推翻。曲面/折片先看截面和端部过渡，再画明暗。
   曲面、卷折或遮挡关系仅靠主视图仍无法说清时，先建立截面与整体的对应，再用正交构造或同一可编辑模型的互补视图核实。可借鉴可用的建模 Skill，但不改变最终交付格式；不强制所有 SVG 安装三维工具。构造视图只是待检验假设，必须逐项与实际参考对应，不能把转动同一模型当成新增实物证据。空间关系未成立，不得进入材质、回装或结束任务。
3. **先看结构图，再上材质。** 临时去掉高光、装饰和易混淆阴影，实际打开填充/轮廓与参考对照。边长改动须体现在实体边界，缩短亮线不算；作者坐标只能证明自己画了什么，不能证明参考如此。
4. **材质服从结构。** 用共同材质色、明度角色、描边、光源和简化方式表达真实材料/厚薄；同一实体跨局部的色阶/粗细衔接，不能每个局部另定一套。材料面不能盖错开口或把连续片画成独立圆头条；结构错误回 P，不以调色解决。
5. **先产出并看独立局部，再看邻接。** 沿用已有独立源，或从当前源精确抽取本项组，保存为保留最终坐标的局部 SVG；逐个改完、导出、实际打开后，另看含足够邻接的固定裁切。不能只在未完成整图上改一处、导出整图，就把它称作独立局部完成。局部与参考同尺度并排，核放大和用途尺寸浅/深底及相关转向；旧 PNG、源可解析或缩小后看不出都不能代替。后续修改只改变当前局部，已核局部原样保留；全部完成才精确回装并重新看整件。
6. **给出具体局部结论。** 有必改就是返工：修源→重导→重看同一问题及受影响关系，留在本项循环；无必改且证据满足才进入下一项。资料/工作未完成不是通过。记录实际观察，不复述规则当证据。

跨局部追踪所属实体的轮廓切线、厚度、材质与遮挡；接点消失先查原构件/层级，不另补一小截。已确认杆线穿孔后再露出时，先看去遮挡的完整构件，核入口/被遮段/出口路径和粗细相容，再恢复遮挡；未知内部不强行重建，出口亮点也不能另画来冒充同一杆。

## A/W：严格审核与返工入口

回装保留当前已核局部的尺度、坐标和姿态；任何改动都使受影响局部/邻接旧结论失效。原样回装仍须新整件审核。项目的整批失效规则由项目规定，不强加别处。

每个接点先核实物连接，再核目标投影中的前后关系，最后核 SVG 绘制顺序；三者不能互相替代。屏幕上相碰不证明连接，调图层也不能修错几何。固定同一接点裁切对比修改前后，实际打开浅深底放大图及用途尺寸图；不为补支承或提升可读性擅加零件、移动真实接口或改变指定视角。

**面与线必须分别审遮挡。** 沿每条折线、卷边内外缘、接缝与反射线，指出它属于前侧还是后侧、在哪里开始被遮住、何处重新露出。前景面遮住背面后，背边不能仍浮在最上层；不能把全部轮廓最后统一描一遍而形成透画。构造/导出时只保留当前视角实际可见的线段，附着界面也不能凭导出切分变成实物接缝。去掉材质装饰实际检查一次结构线，再恢复材质重查；模型多视图正确不证明 SVG 的线条层级正确。有透画立即退回受影响 P/V，修后打开相同局部与整件验证，不靠颜色压暗掩盖。

自审实际走完完整周界，再逐项查全部清单、接点和跨局部实体：局部对了是否装错面、方向/透视是否相容、缺口是否被盖住、同一杆/片是否仍连贯。打开完整参考、当前整件放大、1×浅深底与用途转向；旋转同一图不等于新相机视角。

独立复审可用且项目允许时必须执行：给当前完整图/参考、局部源、用途约束和画风样本，让其实际看图；不提供旧通过或想要的答案。只读审阅不代画。逐条在实图核实建议，采纳/拒绝均有依据；审阅者一致也不能覆盖可见缺陷。

审核先查会推翻其他结论的项：实例覆盖/所属与形成路径 → 共同尺寸、投影和遮挡 → 跨局部连续与接触 → 材质与用途可读性。前项失败，后项只能作为有限观察，不能汇总成通过。使用构造模型时查实际产物，不以脚本意图证明连续、厚度或无相交；例如接近/重合的界面未必相连。返工后从受影响的最早关卡重新取证，不能复制旧审核签字。

**审核缺陷必须落到版本、参考位置、当前位置、违反的关系与退回阶段。** 有明确必改即返工；不明确的指控先查，不为满足审阅去补虚构零件。局部审不能升级为整件审，静态审不能升级为用户认可或实装。

## 不以未完成结束

有必改项就持续完成当前授权范围的修正和复审；不能因为已工作很久、产出很多文件、提交一次、代理说通过或要发总结而停。修一处后复核它影响的已有要求，不能等用户再次指出才补查。

证据不足先实际查找；工具失败换可用方法。确实需要用户输入/权限或外部资源才可继续时，保留未完成状态，准确说明缺口与已尝试动作，继续能独立推进的部分；不编造补齐，也不反复空转。不越过用户暂停/停止点、不擅自集成/发布。

交付说明当前版本、实际审核范围、已解决问题与仍未验证项，附可打开的源和证据。哈希只防串版，不证明质量；完成声明不能大于当前证据。
