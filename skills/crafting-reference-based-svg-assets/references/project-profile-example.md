# 项目配置示例

把实际约束保存在项目指令中；此文件列出需要明确的配置项，不提供通用禁令。最新用户指令优先，任务当前进度和版本应保留在项目状态记录，而非通用Skill中。

- 制作方法：可编辑源格式、工具、分辨率、允许/禁止的方法。
- 统一画风：已有认可样本、描边、光源、材料简化和细节密度；不同材料保留各自色系。
- 独立局部与组装：哪些部位需要先单独做好，何时回装，谁负责实际看图。
- 并行与批次：作者分工、能否并行、能否批量，以项目约束为准。
- 安装用途：指定安装端、目标尺寸/转向和可见连接要求。
- 审核：采用的结论词、独立复审要求、发现问题后的失效范围；只有项目明确要求时才撤回整批。
- 外部参与者：指定工具/模型、允许的输入数据与实际返回记录；调用成功不能等于准确看图。
- 授权与停止点：制作/静态复审/用户认可/集成分别如何确认，当前暂停要求在哪里读取。

示例不包含真实项目名、用户路径、私人素材或模型凭据。不要把别人的项目规则复制为所有任务的默认值。
