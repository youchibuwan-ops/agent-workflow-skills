# 视觉诊断：从看起来不对找到可见原因

在完整比例、局部姿态、薄厚、材料或连接说不清时使用。先看参考和当前图，再读这份提示对照；这些是观察方法，不是预设缺陷清单。

## 形制与周界

- 用同一实物基准看长宽关系、肩腰、凸凹和端部弧线。稳定基准不是各自画布中心，也不是外加安装柄的总长度。
- 走完一侧到尾端、再沿另一侧返回，单独打开被整图缩小的端部。端部以上/以下仍属于整件；不要把琴枕、接缝或“这轮没改”当作审查边界。
- 已有长短角、四弦或两拾音器不能证明琴型正确。先比较相互位置与整个外轮廓，再用部件细节解释身份。
- 同一局部的相对尺寸也要落到实体边界：逐条定位待比较边的起止点、遮挡与端部收缩，再核长短、宽窄和两端切角。需要时暂时去掉高光/装饰，看填充轮廓是否仍成立。缩短亮线不能代替缩短自由边；坐标长度只能核当前稿，不能冒充照片实测。
- 异款辅助图不提供目标的精确尺寸，却可能在同排共同尺度内清楚显示端段、缺口、宽根与短自由边的相对跨度。先核实际宽度方向，再量同身份边界并保留误差，回主图排除明显误读；不能把资料笼统归为“结构图”而丢掉这些约束，也不能强行等分或用筒口中心代替筒段端界。
- 区分真实曲率差、描边造成的外扩、相机透视与照片反光。叠图可定位疑点，不能以像素差阈值定美术通过。

## 方向、投影与邻接

先把自身形状与整件姿态分开。两个投影一长一短，不证明实物用了两种长度；同类铰接件先核是否共享形状、各绕哪个轴转动，再看投影。平面框架倾斜后也可显得弯折，不能直接把屏幕拐点写成深度弯。重复件共形、对称或共面都是有待实图/规格核实的候选，不是默认真相。

资料少时先做有约束的推理：为关键歧义列候选，分别预测它们应有的接口、连续路径、遮挡与运动，再用已有证据排除矛盾。构造草图只检验这些预测；无穿插、连成一根或能贴一张图仍不能证明真实形状。优先补能区分候选的一项证据，不机械收集大量图片。只有关键分歧确实不可判定时才提出最小补拍/测量或假设选择；非关键隐藏量保留有限假设，不任意精确化。

- 分别找到片面朝向、真实轴段、进入外壳/木边的点，以及被遮住的部分，再判断方向。
- 例如贝斯调弦钮的侧后调节轴，与琴头正面的卷弦柱并不处于同一条可见实体线上。不能把“按钮中心→正面柱中心”当实际短轴角度。
- 同一种零件在不同安装位的投影可不同。分别核宽面、肩部、收口、短轴和侧缘入口；一个通用三叶图标旋转四次不等于核过四枚。
- 独立局部保留邻接参考。回装后再次看遮挡与间隙；孤立时正确的片/轴可能被厚描边吞掉、被外壳挡错或装反。
- 对真实重复构件可复用材质和合理几何，但不能用“同类零件”跳过各自姿态或连接检查。
- 多腿构件要逐条追到各自入口，并核入口之间的片材连续与断口；不能把两处缺口合成一个，或只靠前景面遮住两个端点。辅助视角显示的明显断口与主图暗部冲突时，先纠正主图判读，不以“图已看过”略过冲突。
- 填暗色不是孔隙证明，提亮也不是实体证明。先核边缘转折与相邻面的空间关系，再用画风允许的明暗表达它。

## 透视落实到局部和整件

先在主参考找同一组面/轴的方向，再核当前局部。平行实物边在斜视图中未必屏幕平行；不要把正面辅助图的角度或长度直接贴进目标投影。局部沿整件共用尺度定位，核两端的前后顺序、可见面的宽窄和遮挡，而非单独把端面转得像椭圆。

圆杆/卷口要一起核筒身轴向、两端端面和邻接板面；端面方向、插入/露出路径与厚度必须相容。折片要核相邻面的共同折线和转折方向，不能用互不相容的两块形状拼成一个面。没有足够视图时标明当前投影可确认的关系，不虚构精确相机或内部结构。

使用相机拟合工具前，先核每组二维／三维点是否指向**同一物理位置**。曲线投影的最高点、最宽点会随视角换到不同材料位置，不能直接当固定控制点。用分散且身份明确的锚点拟合，另留未参与拟合的边界与负空间复核；两根点对齐或低拟合残差不证明整体形状、深度与相机已恢复。比较几何版本时固定已核相机，分别记录相机误差和几何差异。

## 阴影与结构分开核

- 单张图里的暗带可能是投影、反射、接缝或真实孔隙；先描述不确定的是哪两片面、哪段边缘或哪个接点。不要将暗色轮廓直接描成实体台阶，也不要通过提亮照片臆造细节。
- 找能分离这些关系的其他角度或光照；让主图约束目标投影、辅助图解释连接，不能把不同相机/型号的局部强贴到主轮廓。没有共同尺度的近照只作定性依据。
- 完整参考和当前图均要看；深底难读与结构画错分别记录。结构已查清后，可在项目画风内调整材质明度与边缘分离，再检查浅深底，而不照搬照片的环境投影。

## 截面与尺寸一起核

先确定比较的是哪两条实体边：两端在哪，属于同一面还是折起后的自由边，是否受斜切/遮挡缩短。上下是屏幕方位还是实体高度不明确时先定位，不直接移动某条线。

对卷/折片沿根部→凸起→回转→自由边读截面，并核两端如何展开到邻接板。把高光去掉检查填充轮廓；圆脊可以简化，不能因此把开口卷片画成封闭筒或平倒角。其他型号能解释结构，不授予任意端点、半径或长度比。

几何和明暗分开检查再合看：临时结构图正确不证明材质图仍正确；材质图好看也不能补缺失的几何。修改一条边后回查同项的宽度、端部、投影与接点，不只复核最后一句反馈。

## 材料由厚薄和面决定

先问它是薄平片、弯折片、圆杆、厚壳还是软材质，再安排明暗。

| 错读征兆 | 需要核实与修正的关系 |
|---|---|
| 薄镍片像圆牌/气球 | 看下收与完整投影；核是否整面渐变加肩部内暗圈制造鼓圆感。用适合实物的平面、细边和反射表达薄厚 |
| 短轴像一根贴上的线 | 看轴端形状、片/舌的前后关系和进入木边/外壳的位置；必要时画窄实体面与侧面，而非只加粗圆头描边 |
| 黑塑料像金属横箍 | 比较外壳与凸耳是否同材质，亮边是否过强；螺丝/磁柱与塑料体分开 |
| 全物件染同一种蓝绿 | 核木、漆、橡胶、塑料、镍色各自固有色和明度角色，统一描边/光源/简化方式 |
| 沿用旧调色板却把黑漆片画成亮金属 | 撤回颜色通过；对照主参考区分涂层、裸材与反光，再用认可画风表达其本色/明度关系。同一片的卷边与板面仍是同材质；换光照不等于换材质，旧色值与内部一致都不能证明本项正确 |
| 颜色很像但整体仍违和 | 回到比例、完整轮廓、部件朝向和相对位置，不能再靠装饰线挽救 |

渐变、圆曲线或平面颜色本身没有统一对错。平薄金属可以有强反射，圆杆可以有渐变；依据当前参考的几何与项目画风决定。不要把“所有金属必须平涂”写成新规则。

## 与记忆冲突时查实图

把原图按像素放大查真实装配，再修判断。某款拾音器的凸耳数、磁柱排列或某款弦钮的轮廓不代表整类产品；厂家零件斜视图也不自动代表主参考的型号、手性、年份或装配投影。

只审当前用途必须表达的可见关系。不凭一张前视图断言内部机械失效，不强迫补出不可见背面；但不能以“背面不可见”回避图上已经存在的断接或错误遮挡。

## 固定对照与负空间

同一轮几何比较固定主图、裁切、尺度和目标姿态，先看分散端点的共同偏移，再判断局部变形。若共同偏移来自对齐，不逐点歪曲形状去补；若几何依据要求改变整体基准，先建立新基准，旧对照不继续沿用。

除外轮廓，也比较实体之间的开口、间隙和露出范围。暗区不是孔隙蒙版；叠图只定位可见差异，不给通用相似度 PASS。对深度问题继续用互补视角核实，不能把厚度压平来赢一个投影。

对每个接点分三问：实物怎样接？目标图谁遮谁？当前 SVG 是否按该关系绘制？连续长构件可按遮挡分段绘制，但共享轴、截面及整体轮廓；不能因分段产生新接缝、粗细跳变或断开的明暗。

线条另查一遍：中央卷起的前侧面已经挡住后边时，后边的轮廓/折线也必须随之消失，不能透过前面。深色线不自动是外轮廓，模型投影线也不自动可见。导出器若最后统一覆盖全部边线，须执行真实可见性裁切或正确深度层级，而非只验证面顺序；抽出独立曲面造成的根部边界不是实物切口。逐段追线的起止和遮挡，再与完整卷片、邻接面合看。

同一片材拆成局部后，填充抗锯齿、暗底色与简化路径也可能在连续附着处叠出假接缝，模型连通、色号相同和组哈希一致都发现不了。放大检查平滑连续面的分组交界，再看用途尺寸浅深底；定位是实际切边、材质阶、隐藏线还是导出覆盖。修导出覆盖后重看受影响局部和整件，保留真实自由边与窄露缘，不以加亮补线、删边或改实体来遮住人工接缝。

## 反复失败时按原因退回

| 实际漏步 | 当下处理与避免再漏 |
| --- | --- |
| 只做一小块便停 | 回完整清单明确当前项及剩余项；当前项循环到无必改，全部局部完成才回装和做新整件审核 |
| 局部正确、整体断开 | 找所属实体与共用基准，沿整根/整片追踪跨界处；同时打开局部邻接与当前整件，修后重新追踪 |
| 不认真反复对照 | 每次改源重新导出，打开固定坐标的参考/当前图；回查本项全部约束及受影响邻接，不能只看最后改的亮线 |
| 查资料却不用 | 指出图中具体位置→确认/排除哪种解释→影响当前哪个边/面/接点；不能映射时不算该关系已查清 |
| 有图却仍凭印象判结构 | 回 R，分实体、截面、连续/断开、轴/面及前后关系；解释与互补图冲突就撤回解释 |
| 把阴影补成实体 | 先找可见材料边与互补光照/角度，核遮挡和接触；不能只因暗块或别人说缺件就增画材料 |
| 修结构忘尺寸、修尺寸丢透视 | 回读同项全部约束，先无装饰结构图联查，再上材质并回装；不把各项独立打勾 |
| 未对照实物就宣称颜色一致 | 将该声明记为错误并撤回；重新核主体色块、材料之间的色相/明度和明暗面积，逐局部及整件实际看图；不得只检查色号相等 |
| 代理/脚本通过仍有明显错 | 撤回受影响结论，回到当前图定位具体差异；审阅票数、哈希和导出日志都不代替图审 |

这些是返工方法，不是对每个新物件预设同样缺陷。

## 外部意见的采用例

模型说“两个弦钮互相遮挡”，先在当前图定位那两枚。若图中有清楚空隙，拒绝这条；不能因同一返回里有一句正确的材质建议就接受整段。分别保存实际观察、采用理由与拒绝理由，不将返回字数或审阅人数当证据。
