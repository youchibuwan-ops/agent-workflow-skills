# 视觉诊断：从看起来不对找到可见原因

在完整比例、局部姿态、薄厚、材料或连接说不清时使用。先看参考和当前图，再读这份提示对照；这些是观察方法，不是预设缺陷清单。

## 形制与周界

- 用同一实物基准看长宽关系、肩腰、凸凹和端部弧线。稳定基准不是各自画布中心，也不是外加安装柄的总长度。
- 走完一侧到尾端、再沿另一侧返回，单独打开被整图缩小的端部。端部以上/以下仍属于整件；不要把琴枕、接缝或“这轮没改”当作审查边界。
- 已有长短角、四弦或两拾音器不能证明琴型正确。先比较相互位置与整个外轮廓，再用部件细节解释身份。
- 区分真实曲率差、描边造成的外扩、相机透视与照片反光。叠图可定位疑点，不能以像素差阈值定美术通过。

## 方向、投影与邻接

- 分别找到片面朝向、真实轴段、进入外壳/木边的点，以及被遮住的部分，再判断方向。
- 例如贝斯调弦钮的侧后调节轴，与琴头正面的卷弦柱并不处于同一条可见实体线上。不能把“按钮中心→正面柱中心”当实际短轴角度。
- 同一种零件在不同安装位的投影可不同。分别核宽面、肩部、收口、短轴和侧缘入口；一个通用三叶图标旋转四次不等于核过四枚。
- 独立局部保留邻接参考。回装后再次看遮挡与间隙；孤立时正确的片/轴可能被厚描边吞掉、被外壳挡错或装反。
- 对真实重复构件可复用材质和合理几何，但不能用“同类零件”跳过各自姿态或连接检查。
- 多腿构件要逐条追到各自入口，并核入口之间的片材连续与断口；不能把两处缺口合成一个，或只靠前景面遮住两个端点。辅助视角显示的明显断口与主图暗部冲突时，先纠正主图判读，不以“图已看过”略过冲突。
- 填暗色不是孔隙证明，提亮也不是实体证明。先核边缘转折与相邻面的空间关系，再用画风允许的明暗表达它。

## 阴影与结构分开核

- 单张图里的暗带可能是投影、反射、接缝或真实孔隙；先描述不确定的是哪两片面、哪段边缘或哪个接点。不要将暗色轮廓直接描成实体台阶，也不要通过提亮照片臆造细节。
- 找能分离这些关系的其他角度或光照；让主图约束目标投影、辅助图解释连接，不能把不同相机/型号的局部强贴到主轮廓。没有共同尺度的近照只作定性依据。
- 完整参考和当前图均要看；深底难读与结构画错分别记录。结构已查清后，可在项目画风内调整材质明度与边缘分离，再检查浅深底，而不照搬照片的环境投影。

## 材料由厚薄和面决定

先问它是薄平片、弯折片、圆杆、厚壳还是软材质，再安排明暗。

| 错读征兆 | 需要核实与修正的关系 |
|---|---|
| 薄镍片像圆牌/气球 | 看下收与完整投影；核是否整面渐变加肩部内暗圈制造鼓圆感。用适合实物的平面、细边和反射表达薄厚 |
| 短轴像一根贴上的线 | 看轴端形状、片/舌的前后关系和进入木边/外壳的位置；必要时画窄实体面与侧面，而非只加粗圆头描边 |
| 黑塑料像金属横箍 | 比较外壳与凸耳是否同材质，亮边是否过强；螺丝/磁柱与塑料体分开 |
| 全物件染同一种蓝绿 | 核木、漆、橡胶、塑料、镍色各自固有色和明度角色，统一描边/光源/简化方式 |
| 颜色很像但整体仍违和 | 回到比例、完整轮廓、部件朝向和相对位置，不能再靠装饰线挽救 |

渐变、圆曲线或平面颜色本身没有统一对错。平薄金属可以有强反射，圆杆可以有渐变；依据当前参考的几何与项目画风决定。不要把“所有金属必须平涂”写成新规则。

## 与记忆冲突时查实图

把原图按像素放大查真实装配，再修判断。某款拾音器的凸耳数、磁柱排列或某款弦钮的轮廓不代表整类产品；厂家零件斜视图也不自动代表主参考的型号、手性、年份或装配投影。

只审当前用途必须表达的可见关系。不凭一张前视图断言内部机械失效，不强迫补出不可见背面；但不能以“背面不可见”回避图上已经存在的断接或错误遮挡。

## 外部意见的采用例

模型说“两个弦钮互相遮挡”，先在当前图定位那两枚。若图中有清楚空隙，拒绝这条；不能因同一返回里有一句正确的材质建议就接受整段。分别保存实际观察、采用理由与拒绝理由，不将返回字数或审阅人数当证据。
