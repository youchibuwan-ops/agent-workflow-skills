# DSH 默认受控入口

这是宿主适配包，和只复制 `SKILL.md` 的安装方式不同。通过这里的 `dsh` 命令启动的会话会自动接入工具门禁，不需要每次再贴流程提示词。网页 DeepSeek、直接运行原版 SDK、其他客户端及已经打开的会话不在这个入口的控制范围内。

当前安装包的准确验证状态以随包交付的验证记录为准。纯单测、真实原生调度、真实模型整链和人工界面操作分别记录；不能互相代替。

当前版本及准确验证范围见 [R56 交付记录](../evidence/global-entry-r56-20261026/README.md)：统一分开原生界面管理与模型执行，元数据不再迁移整份大历史，界面能力清单与实际接线一致，未纳管的后台执行器关闭。完整回归、Codex 新会话/冷恢复、DSH 官方模型、实际游戏项目读取和界面操作分别留证；未覆盖项不计通过。本机验收不代表下载者已安装或启用。

## 给同学安装

1. 完整解压安装 ZIP，双击 `安装DSH.cmd`。Windows x64 首次安装需联网下载固定版本的官方 Node 和 DSH 依赖，无需预装 Codex 或旧包。
2. 使用下面的固定入口启动；如果希望正常终端的 `dsh` 命令也进入受控版本，再单独双击 `启用默认DSH.cmd` 并重开终端。此项会调整用户 PATH，原值保留备份；普通安装不会替换机器人或其他既有客户端的启动入口。
3. 在自己的终端设置自己的 `DEEPSEEK_API_KEY`，再运行固定入口。不要把真实密钥放进安装包或发给同学。
4. 打开终端输出的本机网址。在 Web 中添加并选择实际项目目录，核对顶部工作区名称后再提交任务。

```powershell
$env:DEEPSEEK_API_KEY = '你自己的密钥'
cd '你的项目目录'
& "$env:USERPROFILE\.agent-workflow\global\dsh.cmd" web
```

已选择启用默认命令时，也可运行 `dsh web`。固定入口始终为：

```powershell
& "$env:USERPROFILE\.agent-workflow\global\dsh.cmd" web
```

该入口不会自动打开浏览器。Web 的默认工作区可能在文档目录，**不能只凭终端的 `cd` 判断保存位置**。
先在 Web 中选择正确目录，再提交任务、选择方案和反馈；也可连接受控 SDK 或 ACP 客户端。
安装器准备官方 `headless`、`sdk`、`acp`、`web` 四种配置。`headless` 只处理一次提示后退出，
不会交互等待后续选择；不能用它反复退出重开来完成同一套方案与反馈流程。
冷恢复会重新核验事实并重新提供方案，旧选项和回执不能重放。安装器不自动调用付费模型。

## 日常操作

- 宿主先核实际 Skill、许可证和来源，再接受有依据的方案卡。
- 在同一受控会话中用 `/workflow choose <方案ID>` 选择，只有选定产物路径可写。
- 当前初稿经过校验后，实际用户用 `/workflow accept` 验收；模型不能代用户选择或验收。
- `/workflow status` 查询当前阶段。模型说“完成”不等于宿主完成；缺证据、失败测试或等待反馈仍显示未完成。
- 普通进度追问保留当前任务；新的修改要求重新打开受影响阶段。

结构检查只证明本次检查覆盖的语法、字节或可读性。它不自动证明事实正确、英语流畅、视觉好看或用户满意。当前通用入口支持受控来源、文本产物、原生权限读写与受限 Python 方法；缺少视觉检查或必要 Skill 更新能力时会阻断相应阶段，不能把能力缺口写成通过。最小 SDK 模板的持续终端缺精确进程结果，仍明确拒绝相关读写能力。

## 完整性与原有环境

每次启动先核发行源码，再核实际安装的完整依赖树。锁文件和下载摘要不代替安装后核验。安装文件、状态及 PATH 备份放在用户目录 `.agent-workflow/global`；账号和密钥不随包分发。升级保留旧版本。安装 DSH 按钮不替换 Codex 原应用或自动接管其窗口。

本机 Codex 使用 `Codex-Controlled` 快捷方式进入已核验的私有桌面。R37 修复正常模型/推理设置，实际补入本机账号原生目录中的6.1 Sol，冷启动后同会话实际调用仍保留所选型号/档位；后续新型号须重新核取原生目录。普通原版窗口与此聊天不会被追溯接管。DSH 安装按钮不分发或替换 Codex 桌面，不能把本机 Codex 验收当作同学电脑已安装它的证明。仅可声称已记录的功能链通过，不能扩大为所有桌面功能均已验收。

开发者复测见 [验证边界](global-testing.md)、[DSH 原生边界](../hosts/dsh-global/VERIFICATION.md) 与 [真实模型探针](../hosts/dsh-global/probes/README.md)。历史 preview1 的证据继续固定在其原提交，不能转给这个入口。
