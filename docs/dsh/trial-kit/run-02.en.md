# run-02: preview.3 retest

[Chinese step-by-step commands and prompts](run-02.zh-CN.md) · [Install](../install.en.md)

Download the maintainer's fixed-commit ZIP and extract into a new folder. Confirm
`0.1.0-dsh-preview.3`. Keep all previous results and the failed automatic SVG run.
This is a protocol, not a passing test record. No Codex/Git/Node/Python is required
for installation or the CSV checker; model tasks still need the host's actual tools.

1. Create a new run-02 folder outside the repository, with separate CSV/SVG task
   folders and an evidence folder. Give the model only fresh task inputs. Before
   CSV execution, run CSV-Check.cmd Snapshot with a new baseline path in evidence;
   it must succeed and must never be backfilled after the task. Preserve original
   SVG inputs separately. Record the package commit/ZIP hash, Desktop/model/Windows
   versions and PowerShell7 version.
2. From real PS7 run Check. If an older managed distribution remains, back up both
   receipts and run the NEW package's Update. If absent, Install; do not call this a
   cross-version update. Keep full output, immediate exit codes, command index and
   before/after receipts in separate per-Skill folders. Do not force unmanaged copies.
3. Personally create fresh GUI chats in official Desktop for each explicit task,
   using the prompts in the Chinese protocol. Capture the catalog, real Skill tool
   body including its end/base path, reference-read responses, rendering/viewing
   actions and errors. Export tool cards, or copy text/screenshots with redaction.
   Fresh background subagents and agent self-reports do not prove GUI novice usage.
4. After CSV, run CSV-Check.cmd Verify against that task's pre-task baseline. Keep
   PASS/FAIL output and exit code. Keep original CSV/SVG, revisions, editable locals,
   rendered PNGs, scripts and validation outputs; do not repair output to manufacture
   a pass. Missing rendering capability or a failed run remains incomplete.
5. Test unprompted selection and identical-prompt A/B separately using fresh folders
   and the original protocol. Remove Skill-loading requests and reference filename
   hints as well as slash names. A must actually lack the Skills. If an isolated
   account/baseline is unavailable, mark unverified. Negative cases need actual tool
   events. Every CSV run requires its own pre-task snapshot.
6. Back up current receipts, Uninstall, Check, then independently confirm BOTH actual
   target directories absent and create a new GUI chat to verify catalog absence.
   Uninstall exit0 and subsequent Not installed/exit1 are expected; Check stops at
   the first missing Skill and alone does not prove both absent.

Zip only selected run-02 evidence, with a missing/untested/incomplete checklist.
Keep originals locally, redact usernames/emails/keys/tokens/cookies/Authorization in
sendable copies, and exclude credentials, .env/.npmrc, full environments and private
DSH profiles/sessions/storages. QQ Bridge not installed remains unverified; do not
install it just for this test. The old failure and missing historical traces stay
unchanged. Nothing here claims run-02 completion or formal acceptance.
