## What was repaired

The discovery Skill now ties each adopted producer, validator, previewer or fallback
to actual returned method evidence, applicable license text, current-use scope and
a visible decision before use. Missing/truncated/unrelated returns remain unresolved;
a download or an adoption statement cannot substitute for inspection. Changed items
reopen only their own gate. Routine established work avoids redundant discovery.

The entry description routes prior failures and nontrivial format work into matching
even when its programming language is familiar. Delivery gaps require a mature
production/check Skill or maintainer workflow, followed by checks selected for actual
fault coverage. Text extraction, structural/layout diagnosis and page inspection
answer different questions. A new library alone does not establish that coverage.

The SVG Skill also inventories repeated instances by face/location and actual
visibility in each view before aggregating counts, including read-only preparation.
The [discovery diagram](discovery-workflow.md) and [SVG diagram](svg-workflow.md)
show the order and rework loops. These are instructions, not a host tool-call firewall.

over shared upstream/network/provider caches. Temporary account copies are removed;
neither credentials, hidden instructions nor full raw RPC are published.
