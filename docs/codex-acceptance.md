## Independent output checks and compatibility limits

All four PDF artifacts pass independent checks of every 36 rows/108 cells, selectable
bilingual text, repeated headers, page bounds and actual complete-page Poppler review.
Root and a separate read-only reviewer opened all current pages. Exact-byte controls
and both SVG three-image/four-hole/continuous-fold preparation checks also pass.
SVG smokes do not establish full local production or assembly quality.

V2 trial 2 emits FontBBox warnings. V3 trial 2's corrected used text matches exactly,
but unused ToUnicode entries still have **1,884 odd-length tokens**, causing **5,652
pypdf warning lines** in independent review. These are retained compatibility defects,
not suppressed or silently repaired after the run. Current text extraction and
Poppler pages pass; arbitrary characters, other viewers, strict PDF conformance and
physical printing remain untested. The fixed task never required universal PDF conformance;
no new conformance gate was added after observing the result. Do not recommend the
trial's CMap repair as a generally validated recipe.

The private checker initially missed kerning-spaced `ROW -01`; consistent existing
whitespace normalization fixes that parser assumption. Cell values/order and all
visual criteria are unchanged and were rechecked across every artifact. This is a
checker repair, not a changed expected result or fabricated positive comparison.
